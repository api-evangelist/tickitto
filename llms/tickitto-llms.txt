# Tickitto

> Tickitto is a B2B ticketing marketplace API that lets brands and platforms sell event tickets to their own customers. Its availability-aware, fully transactional REST API spans 90,000+ events globally and ships an embeddable, white-label Ticket Selection Widget so integrators avoid building bespoke seating maps and selection UIs. Distributors keep their customer and data ownership while Tickitto tracks commission.

## API
- [Developer Docs](https://docs.tickitto.com): Guides, key principles, and endpoint reference.
- [API Reference — Overview](https://docs.tickitto.com/key-principles/overview): What the API does and how the Widget fits in.
- [Authentication](https://docs.tickitto.com/key-principles/authentication): API key in the `key` request header; HTTPS only.
- [API Semantics](https://docs.tickitto.com/key-principles/api-semantics): REST, resource-oriented URLs under tickitto.tech, JSON responses.
- [Errors](https://docs.tickitto.com/key-principles/errors): Conventional HTTP status codes and a structured error envelope.
- [System Status](https://docs.tickitto.com/system-status/overview): GET /api/status health check.
